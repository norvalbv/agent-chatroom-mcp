## Working through the spec

**Step 1: What double does `1e-7` actually store?**

I need the exact real-number value of the nearest double to 1e-7, since the spec says rounding "uses the exact binary value of the number."

Writing 1e-7 = m·2⁻²⁴ gives mantissa m = 10⁻⁷·2²⁴ = 16777216/10000000 = 131072/78125 = 1.6777216 exactly (as a real number). To store this in 52 fraction bits, I need floor(x₀·2⁵²) where x₀ = 52947/78125 (the fractional part).

Using the identity 78125·128 = 10,000,000, this reduces to exact integer arithmetic:
- N = 52947·2⁵² = 238,452,089,470,385,651,712
- N·128 = 30,521,867,452,209,363,419,136
- N/78125 = N·128/10⁷ = 3,052,186,745,220,936 remainder 3,419,136/78125

Since the remainder (26712, after dividing by 128) is less than 78125/2, **rounding is downward** — the stored double is *slightly less than* 10⁻⁷.

**Step 2: Exact value of the double**

Working this through: D·10⁷ = 1 − 3,419,136/75,557,863,725,914,323,419,136 ≈ 1 − 4.5252×10⁻¹⁷.

So D ≈ 9.9999999999999995474811...×10⁻⁸ — that is, **seventeen consecutive 9's** before the digit stream turns to "5474811...".

**Step 3: Apply the `%.16g` algorithm**

Per spec, first compute X: round the value to P−1=15 digits after the point in e-style (16 significant digits total). The 16 kept digits are all "9", and the 17th digit (the round digit) is also "9" — round up. This cascades through all sixteen 9's, carrying out to:

    1.000000000000000 × 10⁻⁷   →   X = −7

Now test the branch: "If P > X and X ≥ −4": 16 > −7 holds, but −7 ≥ −4 is **false**. So e-style applies, with precision P−1=15 — using the *already-rounded* value: `1.000000000000000e-07`.

Strip trailing fractional zeros (no `#` flag): `1e-07`.

**Diagnosis of the disagreement:** Implementation A's output `9.999999999999999e-08` has 16 nines with no rounding carry applied — it evidently took the first 16 significant digits of the exact value without propagating the carry from the 17th digit (also a 9) through the exponent. The spec is explicit that X must be computed "after rounding," which forces the carry cascade here.
