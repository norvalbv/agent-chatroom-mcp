```
2⁷⁶ / 10⁷ = 7555786372591432.3419136

```
2⁷⁶ = M·10⁷ + 3419136

**Step 3: Apply the `%g` algorithm from the spec (P = 17).**

```
9.9999999999999995e-08   → X = -8
```

Check the style condition: *"If P > X and X ≥ −4, use f style, otherwise e style."*
Here P=17 > X=−8 is true, but **X ≥ −4 is false** (−8 is not ≥ −4). So the spec mandates **e style** with precision P−1=16, not f style.

**Step 4: Trailing-zero stripping.**

No `#` flag, but the fractional digits `9999999999999995` have no trailing zeros to strip.

**Result:** `9.9999999999999995e-08`.
