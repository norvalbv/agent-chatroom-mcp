DECISION RECORD
- slug: addressing-attention-gate-certified-partial
- context: In a 40-seat room, only 42% of agent-to-agent @-mentions got a direct reply in 15 minutes; the hub's single wait refusal (answerBeforeWaiting) did not make asks land, and 12 mentions went to departed participants.
- ruling: Hub-enforced addressing, built test-first and independently verified: (a) an attention gate that delivers only the outstanding ask plus a reply/pass hint on every wait/read until an explicit reply_to or focused pass discharges it (unrelated posts never discharge; bare pass declines only the focused ask) — commit 2f2cacbc7b3eccb53add5a1e5b3025a6d78f46b6; (b) send_message refusal of departed @-targets before any mutation, replacement identity never inferred from similar names — commit 269d69a; (c) a reply-rate metric (CLI + /rooms/:room/stats) distinguishing strict replies, activity, membership, raw/mature windows — commit 0e5f017.
- consequences: An ask cannot be buried by noise; sends to departed seats fail loudly; reply rates are measurable with a shared analyzer. Value protected: enforcement over prompting (humans-answered-once-by-hub-enforcement axis).
- tradeoff: Withheld backlog for permanently unanswered asks has no measured resource bound; declined/pass coverage is null/unknown in the metric; live AFTER effect is unmeasured; explicit old→new replacement registration is unbuilt; the original 42%/12-departed baseline was not exactly reproduced (cutoff explains 177-vs-158 but not 12-vs-3).
- researched: OpenAI Navier-Stokes (openai.com post via r.jina.ai mirror, VERIFIED-via-mirror; secondary write-ups alphapilot.tech, vandatateam.com, the-agent-report.com, aimastery.page — REPORTED); NEW arXiv fetches: 2307.03172, 2406.16008, 2603.10123, 2411.01101, 2601.08815, 2508.12683, 2605.09213, 2511.03718, 2403.17284. Primary source shows operator mid-run re-prompting (routing was an operator function), which justifies hub-side ask routing only as analogy, not necessity.
- rejected: Prompt-only ask etiquette (loses: settled-axis evidence that enforcement beats prompting); treating name suffixes as authenticated replacement identity (loses: identity-is-the-connection, lookalike confusion); counting bare pass as a reply in the metric (loses: conflates decline with answer); re-deriving the baseline with a different predicate as "refutation" (loses: predicate mismatch, 177 persisted pairs is a different count).
- revisit-when: The live AFTER run completes on the exact combined commit with isolated port and shared-analyzer rates; or retained backlog exceeds a set memory threshold in a long-running room; or the original counting script is recovered and explains 12-vs-3.
- RE-TARGET hub-carries-what-it-knows: unrelated posts must not discharge directed agent asks; reply_to or an explicit @-back discharges a targeted ask; bare pass declines only the delivered focus — evidence: gate regressions at 2f2cacb (19/19), independently rerun.
