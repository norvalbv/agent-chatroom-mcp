DECISION RECORD (ready for `guard-decisions add dashboard-renders-hub-truth`):
- slug: dashboard-renders-hub-truth
- context: A human watching twelve agents cannot trust /ui: the tally/waiting view derives a wrong electorate after a departed standing disagree and never shows read-to-vote quotes; poll() races render cross-room messages and duplicate batches; unscoped writes delete drafts and report failures as success; each /rooms poll re-ships full board/proposal/conclusion state (~1.79 MB/snapshot, ~35.7 MB/min extrapolated) for 66 mostly-concluded rooms.
- ruling: The hub DTO is the single authority the dashboard renders: proposalView emits active-only tally, retained dissent, waiting_count=waiting_on.length and the stored vote quote; seat-side polls/writes capture selection-generation tokens and draft revisions and validate after every await, with seq dedupe; an opt-in brief /rooms sidebar DTO with detail fetched only on selection; a recruits pane fed by the existing /agents. Items are admitted only with in-room reproduction evidence (a)/(b)/(c rule); the verify/* gate recorded it.
- consequences: The human sees the true electorate, provenance and failures; transcripts survive room switches; sidebar transfer drops ~97% at snapshot. Axes preserved: consensus-requires-scrutiny, hub-carries-what-it-knows, identity-is-the-connection, done-means-independently-verified, proposal-is-a-document.
- tradeoff: DTO shape changes touch every proposalView consumer (aggregate tally kept only for compatibility); generation guards add state and regression burden (delayed JSON, out-of-order, overlap, A→B→A fixtures); this run verified diagnoses only — no implementation, no browser validation.
- researched: NEW this run: arXiv:2602.23193 (ESAA, fetched by union-alpha-7, sources/arxiv-2602.23193 — projected views from an append-only event log). Not new: none re-fetched; a room claim citing arXiv:2402.07510 (already on the read list) was retracted as unfetched.
- rejected: exposing hub.wait/SSE to the dashboard (unmeasured benefit; loses to measured correctness fixes); human propose/challenge routes and a Stop button (no reproduced need; deferred); first-500 pagination (cursor advances; not a real gap); a per-key board route alone (does not avoid full-detail transfer); reading 97.3% as proven production savings (projection-size comparison only).
- revisit-when: a maintainer implements the ranked list — each fix ships with its harness; re-open if live traffic still exceeds network budgets with the brief DTO, or a recruits-pane deployment shows lifecycle data a human still cannot act on.
