OOPS: a tiny object language

An OOPS program declares classes and then prints method results.

DECLARATIONS
  CLASS K                 declares class K with no parents
  CLASS K : P Q ...       declares class K with the listed parents, in that order
                          (a parent is always declared earlier in the file)
  DEF m = PARTS           defines method m in the class most recently declared;
                          defining m again in the same class replaces the earlier body
  PARTS is one or more pieces separated by " + ". The value of a method call is the
  concatenation of the values of its pieces, left to right. A piece is one of:
    "text"    a literal string (no quotes inside)
    SUPER     the result of calling a method, see below
    SELF n    the result of calling method n on the current object
    HERE      the name of the class whose method body is running right now (the class in
              which that body was defined)
    OBJ       the name of the class the current object was created from

STATEMENTS
  PRINT K m     creates an object of class K, calls method m on it and prints the result
                (if m cannot be found the result is the text ?m)

METHOD LOOKUP
  To find method m starting at class K: if K itself defines m, that definition is used.
  Otherwise try each parent of K in the order the parents were listed, applying this same
  rule to that parent; the first parent search that finds m decides. If nothing is found
  the lookup fails.
  A call m on an object looks up m starting at the object's class (OBJ).
  SELF n is such a call on the same object.

SUPER
  Inside a method body defined in class K, SUPER calls the method with the SAME name as the
  running method, but the lookup starts from the parents of K (each parent tried in the
  listed order, using the lookup rule above), not from K. If the lookup fails the value of
  SUPER is the text ?super.
  The object stays the same: OBJ, SELF and HERE inside the super method behave as usual for
  that object and for the class of the method body that runs.

OUTPUT
  The printed results, in order, separated by single spaces (no printed result contains a
  space).
